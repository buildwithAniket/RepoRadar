# Profile — what makes a repo relevant to me

This file drives the daily judgment step. Edit it whenever your search or interests change — an
edit here triggers a fresh look at repos previously marked `not-fit` or `maybe`.

This is a **template**, not the real thing — the actual `profile.md` lives in a private
companion repo (see `docs/design.md`'s "Private profile" section) since it contains personal
details (career timeline, financial/immigration specifics) that don't belong in a public repo.
Copy this file to a private location, fill it in, and point `RepoRadar-private` at it.

## Category (priority: high | medium | low)

What makes a repo relevant here. Be specific — vague criteria produce vague judgments. Include
concrete context the judgment step should weigh (a deadline, a tool you're already using, a
constraint that rules out otherwise-plausible matches), not just topic keywords.
