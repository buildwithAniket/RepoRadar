# RepoRadar

A daily scout that judges trending GitHub repositories against a personal profile and publishes the results as a browsable archive, presented through a film-archive metaphor.

## Language

**Repo**:
One GitHub repository as evaluated on a given day, with its metadata and verdict.
_Avoid_: Record, track, archive entry, entry

**Disc**:
The 3D vinyl-record representation of a Repo in the turntable scene.
_Avoid_: Record, canister

**Edition**:
The set of Repos evaluated on one day, identified by its date.
_Avoid_: Digest (except for the generated data bundle), frame, date

**Digest**:
The generated data bundle containing every Edition. A data-layer term only.
_Avoid_: Edition (when meaning the bundle)

**Verdict**:
The judge's call on a Repo: **fit**, **maybe**, or **not fit**.
_Avoid_: Selects, review, pass (display labels only)

**Docket**:
The detail panel showing the focused Repo's verdict, rationale, specs and actions.
_Avoid_: Detail view, card

**Tracklist**:
The searchable, filterable list view of every Repo in the active Edition.
_Avoid_: Playlist, drawer (the drawer is only how it is presented)

**Filmstrip**:
The timeline for switching between Editions.
_Avoid_: Date picker, timeline
